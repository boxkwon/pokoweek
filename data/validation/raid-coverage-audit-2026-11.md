# POKOWEEK 레이드 커버리지 및 상세 가이드 전수조사

- 조사일: 2026-11-20 (Asia/Seoul)
- 대상 주차: 2026-11-09, 2026-11-16, 2026-11-23 시작 주
- 범위: 전 세계 개별 체육관의 실시간 알이 아니라, 해당 기간에 등장한다고 확인된 레이드 보스 로테이션
- 상태 정의: `검증`은 Pokémon GO 공식 공지 확인, `교차`는 서로 독립적인 보조 출처 두 곳 이상에서 확인

## 1. 조사 결론

누락의 주원인은 화면 필터가 아니라 데이터 등록 정책이었다. 기존 `WeekEvent`에는 대표 5성·3성·메가 레이드만 수동 등록되어 있었고, 1성·일반 3성·그림자 로테이션과 다음 로테이션 교체분은 데이터 자체에 없었다. 또한 기존 `전체` 필터는 레이드 이외의 이벤트까지 섞어 반환해, “전체 레이드”의 의미가 분명하지 않았다.

이번 변경은 기존 이벤트를 삭제하거나 승인 가이드를 변경하지 않고 다음을 분리한다.

1. 출처와 확인 상태가 있는 레이드 로테이션 데이터
2. 난이도 필터(5·4·3·1성)
3. 종류 필터(일반·메가·그림자·특별)
4. 상세 가이드 존재 여부

공략이 없는 보스도 일정과 공략 선택 목록에 표시한다. 없는 공략은 “미등록”으로 안내하며 다른 포켓몬 상세로 연결하지 않는다.

## 3. 상세 가이드 상태 정의

- **A — 표준화 완료:** 공통 상세페이지에서 기술·강화·자원·행동 판단 제공
- **B — 부분 적용:** 상세페이지는 있으나 기술·강화·자원 또는 검증 근거 일부 부족
- **C — 구형 상세페이지:** 별도 구형 UI만 존재. 이번 조사에서는 0종
- **D — 상세 공략 없음:** 일정에는 표시하지만 상세 공략 미등록 안내

### 확인이 더 필요한 부분

- Pokémon GO Hub의 현재 로테이션 표기는 11/24 10:00 종료로 읽히지만 기존 POKOWEEK 및 다른 일정 자료는 크레세리아·다크라이·메가다크펫을 11/24 22:00 종료로 기록한다. 기존 값을 조용히 바꾸지 않고 `corroborated`와 충돌 메모를 남겼다.
- 11월 그림자 1·3성의 월말 정확한 교체 시각은 공식 공지에서 확인하지 못했다. 두 보조 출처가 11/20 현재 같은 보스 목록을 제공한다는 사실만 확정해 기록했다.
- 4성 일반 레이드는 세 주차에서 근거가 확인되지 않아 등록하지 않았고 필터도 숨긴다. 메가 레이드를 임의로 4성으로 변환하지 않았다.
