- 레이드: `Dragon Breath` + `Glaciate`
- PvP: `Dragon Breath` + `Glaciate` + `Dragon Claw`

### 4. 특별 기술 습득 조건

- `Glaciate`는 정규화 데이터에서 `elite` 기술로 분류돼 있다.
- 후보는 이벤트 습득 여부 또는 대단한 기술머신스페셜 사용 가능 여부를 먼저 확인하라고 안내한다.
- 화이트·블랙 융합 자체에는 `Glaciate`가 필수 재료가 아니다.
- 다만 선택한 큐레무가 `Glaciate`를 알고 있어야 화이트 융합 시 `Ice Burn`, 블랙 융합 시 `Freeze Shock`으로 변환된다.

### 5. 실제 육성 순서

1. 화이트용·블랙용 큐레무를 각각 선택한다.
2. 각 큐레무의 `Glaciate` 보유 여부를 독립적으로 확인한다.
3. 화이트는 레시라무·블레이즈 에너지·사탕, 블랙은 제크로무·볼트 에너지·사탕을 따로 준비한다.
4. 사용할 폼이 정해질 때까지 큐레무 본체의 큰 강화를 보류한다.

### 6. CP 강화 우선순위

- 후보 결론: **융합 목표 확정 전 큰 강화 보류**.
- 구체적인 CP, 레벨, IV 기준이나 “어디까지 강화”할지는 후보에 없다.

### 7. 기술 해방 판단

- XL 투자 후 성능과 리그별 목표 레벨 근거가 없으므로 사용처가 확정될 때까지 보류한다.

### 9. 별의모래·사탕 투자 우선순위

- 일반 사탕: **조건부**. 융합 재료와 필드 효과에도 큐레무 사탕이 필요하므로 목적을 정한 뒤 강화에 배분한다.
- 대단한 기술머신스페셜: **해당 없음**. `Freeze Shock`은 TM으로 습득할 수 없다.
- 필드 효과를 쓸 계획이면 10분당 별의모래 5,000과 큐레무의 사탕 5개를 따로 확보한다.

### 10. 융합 전후 주의사항

- 제크로무는 분리 전까지 융합된 상태다.
- 분리에는 합체 에너지와 사탕이 들지 않는다.
- 분리하면 `Freeze Shock`이 `Glaciate`로 되돌아간다.
- 후보에는 융합 후 `Freeze Shock`이 없을 때의 복구 행동 순서가 명시돼 있지 않다.

## B-4. 공식 융합 규칙 검토

공식 공지에서 다음 내용은 현재 Evidence와 일치한다.

- 블랙: 큐레무 + 제크로무 + 볼트 에너지 1,000 + 큐레무 사탕 30 + 제크로무 사탕 30.
- 화이트: 큐레무 + 레시라무 + 블레이즈 에너지 1,000 + 큐레무 사탕 30 + 레시라무 사탕 30.
- 합체 상태는 직접 분리할 때까지 유지되며 분리 비용은 없다.
- `Glaciate` 보유 큐레무가 융합되면 각각 `Freeze Shock` 또는 `Ice Burn`으로 변한다.
- 분리하면 특수 기술이 `Glaciate`로 돌아온다.
- `Freeze Shock`과 `Ice Burn`은 일반·대단한 기술머신스페셜로 배울 수 없다.
- 각 필드 효과는 10분에 별의모래 5,000과 큐레무 사탕 5개가 필요하다.

공식 공지에는 현재 Registry에 별도 claim으로 등록되지 않은 추가 주의사항도 있다.

- 융합 폼은 교환, 박사에게 보내기, Pokémon HOME 전송이 불가능하다.
- 각 필드 효과는 다른 필드 효과와 동시에 사용할 수 없다.
- 필드 효과 연장 규칙과 상한이 있다.

이 내용은 현재 후보에 없으며 게시 전 공식 Evidence claim으로 추가할 가치가 있다.

# D. 정확성이 의심되거나 표현을 고쳐야 할 항목

## D-1. 특수 기술 수치가 “출처에 없는 것”이 아니라 “정규화에서 누락된 것”

화이트·블랙 후보는 `Ice Burn`과 `Freeze Shock` 전투 수치가 입력에 없다는 이유로 추천도와 투자를 보류한다. 정규화 JSON에는 실제로 두 기술 수치가 없다.

그러나 Evidence ID가 가리키는 2026-11-16 PoGo API raw 스냅샷에는 다음 값이 존재한다.

| 기술 | PvE | PvP |
|---|---|---|
| `Freeze Shock` | Ice, 위력 160, 에너지 -100, 1,500ms | Ice, 위력 120, 에너지 -60, 30% 확률로 상대 공격 -1 |
| `Ice Burn` | Ice, 위력 90, 에너지 -50, 2,000ms | Ice, 위력 120, 에너지 -60, 30% 확률로 상대 방어 -1 |

따라서 현재 후보의 “수치가 없어 평가 불가”는 **정규화 입력 기준으로는 사실**이지만 **원본 데이터 소스 전체 기준으로는 불완전한 설명**이다. 먼저 Normalizer가 FusionRecipe의 `targetMove`에 해당하는 PvE/PvP 수치를 포함하도록 수정한 뒤 후보를 다시 평가해야 한다.

## D-2. 추천도 3/5는 데이터 신뢰도와 포켓몬 가치를 혼합한다

세 포켓몬 모두 3/5인 직접적인 이유는 성능이 중간이라는 근거가 아니라 비교 자료가 부족하다는 점이다. 이 값은 “실제 육성 가치”보다 “현재 데이터 확신도”를 반영한다.

- 기본 능력치·기술 수치만으로 상대적 레이드/PvP 등급 3을 입증할 수 없다.
- 근거 부족 때문에 추천도를 낮춘 것은 안전하지만, 사용자에게는 실제 성능이 3/5인 것처럼 보일 수 있다.
- `rating`과 `confidence/dataStatus`를 분리하거나, 근거가 부족한 후보는 등급을 게시하지 않는 편이 정확하다.

## D-3. 기술 조합의 유효성과 “최적 추천”은 다르다

- 큐레무의 두 조합은 실제 기술 목록에 존재한다.
- 화이트의 `Ice Fang + Ice Burn`, 블랙의 `Dragon Tail + Freeze Shock`도 기술 습득 가능성은 확인된다.
- 하지만 현재 Evidence는 이 조합이 다른 조합보다 우수하다는 DPS, 에너지 효율, 시뮬레이션 결과를 제공하지 않는다.
- 특히 블랙의 조합은 Dragon 노말 기술과 Ice 스페셜 기술을 함께 쓰는 목적이 설명되지 않는다.

현재 표현은 “검토용 추천 조합”으로는 가능하지만 게시용 “추천 기술”로는 근거가 부족하다.

## D-4. Evidence ID는 존재하지만 해당 결론 전체를 직접 뒷받침하지 않는 사례

| 후보 주장 | 연결 Evidence | 실제 뒷받침 범위 | 판정 |
|---|---|---|---|
| 공격 310이지만 레이드 3/5 | stats, fast move, official move | 능력치·기술 존재는 지원하지만 3/5 등급은 지원하지 않음 | 전략적 의견임을 더 명확히 표시 필요 |
| XL사탕 보류 | pokemon stats | 능력치는 지원하지만 XL 투자 효율이나 보류 결론은 지원하지 않음 | 의견/자료 부족 판단 |
| 별의모래 대규모 투자 보류 | stats + official move | 사실 자료는 지원하지만 투자 우선순위는 분석자의 판단 | 사실과 의견 분리 필요 |
| `Ice Burn`/`Freeze Shock` 수치가 없음 | official move | 공식 근거는 습득 조건만 지원하고 수치 부재를 증명하지 않음 | Evidence 연결 부적절 |
| 기술 해방 미적용 | 없음(`null`) | 판단 근거가 기록되지 않음 | 게시 전 설명 필요 |

## D-5. 폼별 현재 기술 목록과 융합 변환 기술의 관계가 설명되지 않는다

PoGo API current move pool은 화이트큐레무에 `Fusion Flare`, 블랙큐레무에 `Fusion Bolt`를 포함한다. 공식 융합 규칙은 `Glaciate`가 각각 `Ice Burn` 또는 `Freeze Shock`으로 변한다고 설명한다.

현재 후보는 공식 변환 기술만 추천하며 current move pool의 `Fusion Flare`/`Fusion Bolt`가 어떤 상황에서 존재하는지 설명하지 않는다. 데이터 오류라고 단정할 수는 없지만, 폼별 현재 기술 풀과 융합으로 생성되는 특수 기술을 분리해 모델링하고 사용자에게 혼동 없이 설명해야 한다.

## D-6. 지나치게 보수적인 hold/conditional

현재 보류 판단은 가짜 확신을 피했다는 점에서는 바람직하다. 그러나 특수 기술 수치가 raw source에 이미 존재하므로, 화이트·블랙의 별의모래·XL·레이드 평가를 전부 보류한 전제는 재검토가 필요하다.

반대로 특수 기술 수치만 추가됐다고 추천도를 자동으로 높여서는 안 된다. 상대 공격수 비교·보스별 효율·PvP 시뮬레이션이 추가돼야 실제 투자 가치 판단이 가능하다.

## D-7. 세 포켓몬의 육성 순서 중 반복되는 부분

화이트와 블랙의 순서는 사실상 같은 템플릿이다.

1. 변환 기술 확인
2. 노말 기술 확인
3. 특수 기술 수치 보강
4. 제한적 강화

두 폼의 자료 부족 상태가 같기 때문에 반복 자체가 오류는 아니다. 다만 게시용 가이드에서는 각 폼의 실제 역할과 기술 효율 차이가 반영돼야 하며, 현재 상태로는 두 폼 중 무엇을 먼저 만들고 키울지 결정할 수 없다.

## D-8. 근거 없는 CP·레벨 권장은 없음

후보는 특정 CP, 레벨 40/50, IV 수치를 만들지 않았다. 이는 정확성 측면에서 적절하다. 다만 POKOWEEK 행동 가이드로서 “어디까지 키울지”에는 답하지 못한다.

# E. 추가 자료가 필요한 항목

1. **Normalizer 보강**
   - `Ice Burn`과 `Freeze Shock`의 PvE/PvP 수치를 정규화 폼 데이터에 연결한다.
   - 공식 변환 기술과 current move pool을 별도 필드로 구분한다.

2. **레이드 성능 비교 자료**
   - 같은 타입 공격수 대비 DPS/TDO/ER 또는 재현 가능한 시뮬레이션.
   - 어떤 보스·약점에서 각 기술 조합을 사용할지.

3. **PvP 자료**
   - 적용 리그, 목표 레벨, 주요 매치업, 시뮬레이션 버전.
   - 화이트·블랙 폼의 PvP 기술 조합과 해방 필요성.

4. **CP·강화 비용 자료**
   - 레벨/IV별 CP와 강화 비용.
   - 레벨 40과 XL 구간의 실질 차이.
   - 투자 전환 조건을 설명할 수 있는 목표값.

5. **기술 해방 비용과 효과**
   - 각 폼의 해방 비용.
   - 레이드 단일 용도와 PvP 복수 기술 용도의 차이.

6. **Glaciate 획득 경로**
   - PoGo API의 `elite` 표시는 확인됐지만 현재 시점의 대단한 기술머신 습득 가능 여부를 공식 또는 검증 가능한 자료로 재확인한다.

7. **공식 융합 주의사항 Evidence 확장**
   - 교환·박사 전송·HOME 전송 불가.
   - 다른 필드 효과와 동시 사용 불가.
   - 필드 효과 연장 규칙.

8. **폼 간 투자 우선순위**
   - 큐레무, 화이트, 블랙의 역할·기술·자원 효율 비교.
   - 둘 다 만들 수 없는 사용자에게 먼저 선택할 폼을 안내할 근거.

# F. 게시 전 수정이 필요한 항목

우선순위 순서다.

1. **정규화 누락 수정**: `Ice Burn`과 `Freeze Shock` 전투 수치를 정규화 데이터에 포함한다.
2. **후보 재생성/재작성**: 수정된 정규화 패키지로 화이트·블랙 평가와 기술 조합을 다시 작성한다.
3. **추천도와 확신도 분리**: 자료 부족을 3/5 성능 평가로 표현하지 않도록 한다.
4. **기술 추천 근거 추가**: 각 조합의 목적, 상대 타입, 비교 대상, 성능 지표를 기록한다.
5. **특별 기술 누락 시 행동 추가**: 융합 전에 무엇을 확인하고, 이미 잘못 융합했다면 어떤 순서로 다시 확인할지 명시한다. 확인되지 않은 비용은 만들지 않는다.
6. **강화·해방·XL 조건 구체화**: CP/레벨·비용 자료가 확보되기 전에는 게시용 육성 가이드로 승인하지 않는다.
7. **기술 해방 null 설명**: 화이트·블랙에서 해방을 평가하지 않은 이유와 적용 모드를 기록한다.
8. **Evidence claim 보강**: API snapshot 단위의 포괄적 claim을 폼·기술별 주장으로 더 세분화한다.
9. **공식 주의사항 추가**: 전송 제한과 필드 효과 제한을 Evidence Registry와 가이드에 반영한다.
10. **편집 재검토**: 수정 후보에 대해 사용자 핵심 질문 7개가 실제로 해결되는지 다시 확인한다.

# G. 최종 판정

## 판정: 추가 검증 필요

### 판정 이유

- 융합 준비물·기술 변환·분리·필드 효과 비용은 공식 근거와 일치한다.
- 큐레무의 일반 기술 목록과 기본 수치는 정규화 스냅샷과 일치하지만 아직 `needs_review`다.
- 화이트·블랙의 핵심 특수 기술 수치가 원본 PoGo API 스냅샷에는 존재하는데 정규화 데이터에서 누락됐다.
- 세 후보의 3/5 평가는 실제 성능보다 데이터 부족을 반영하므로 사용자에게 잘못된 의미를 줄 수 있다.
- CP 강화 범위, 해방 가치, XL 투자 전환 조건, 폼 간 우선순위를 결정할 근거가 없다.
- 화이트·블랙의 기술 조합은 습득 가능성은 확인되지만 최적 추천임을 입증하지 못한다.

따라서 현재 후보는 구조적으로 `complete`이지만 편집·사용자 행동 기준으로는 게시할 수준이 아니다. 후보·승인 상태는 그대로 유지하고, 정규화 누락과 성능 근거를 보강한 뒤 다시 검토해야 한다.
