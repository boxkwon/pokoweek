## 2. 포켓몬별 행동 가이드

### 방패왕 자마젠타

**결론:** 맥스·강철 전력이 필요할 때 육성한다.

1. 아이언헤드를 배운 역전의 용사 자마젠타를 고른다.
2. 실드 에너지 1,000을 확보한다.
3. 폼 변경 후 아이언헤드가 거수탄으로 전환됐는지 확인한다.
4. Lv.30에서 맥스배틀·강철 역할을 먼저 확인하고, 반복 사용할 때 Lv.40까지 강화한다.
5. Lv.50·기술 해방·맥스기술 투자는 맥스 또는 마스터리그 역할이 확정된 한 마리에만 진행한다.

필드 추천 기술은 `메탈클로 + 거수탄`이다. 거수탄은 이벤트 한정 기술이 아니라, 아이언헤드를 알고 있는 역전의 용사 자마젠타가 방패왕으로 폼을 바꿀 때 전환되는 기술이다. 일반 기술머신으로 직접 맞추는 기술도 아니다. 전체 강철 공격수 순위와 PvP 매치업은 미평가로 남겼다.

### 크리만

**결론:** 도감과 좋은 개체를 확보하되, 즉시 강화는 보류한다.

1. 기존 드래곤 전력과 비교한다.
2. 실제로 사용할 때만 `드래곤테일 + 드래곤클로`를 맞춘다.
3. 필요하면 Lv.30에서 멈추고 사용성을 확인한다.
4. 레이드용 기술 해방·XL·희귀사탕 투자는 보류한다.

레이드 전체 공격수 순위와 PvP 최적 IV·매치업은 검증하지 않아 수치형 순위나 별점을 만들지 않았다.

### 꿈트렁

**결론:** 레이드가 아니라 PvP 목표가 있을 때만 조건부 육성한다.

1. 슈퍼리그 CP 1,500 이하 또는 하이퍼리그 CP 2,500 이하 중 목표를 먼저 정한다.
2. 게임 내 강화 미리보기로 보유 개체의 예상 CP를 확인한다.
3. `진흙뿌리기 + 아이언헤드`를 맞춘다.
4. PvP 투입을 확정했을 때만 `암석봉인`을 두 번째 스페셜 기술로 해방한다.
5. 선택한 리그의 CP 상한 직전에서 멈춘다.

리그별 최적 IV와 매치업은 미검증이다. 따라서 슈퍼리그의 개체 기준을 하이퍼리그에 복사하거나 정확한 최적 IV를 단정하지 않는다.

### 제크로무

**결론:** 크로스썬더를 사용할 수 있다면 전기 레이드용으로 육성한다.

1. 블랙큐레무를 만들 예정이면 융합 파트너로 남길 제크로무를 먼저 분리한다.
2. 자체 육성용은 공격 IV가 높은 개체를 우선한다.
3. `차지빔 + 크로스썬더`를 확인한다. 크로스썬더는 이벤트 제공 이력이 있지만 현재 대단한 기술머신스페셜로 반드시 얻을 수 있다고 단정하지 않으며, 게임 기술 목록에서 습득 가능 여부를 먼저 확인한다.
4. Lv.30에서 전기 약점 레이드의 사용 빈도를 확인하고, 주력이면 Lv.40까지 강화한다.
5. 레이드만 사용할 때 기술 해방은 후순위다. Lv.50은 장기 주력 한 마리에만 투자한다.

### 레시라무

**결론:** 크로스플레임을 사용할 수 있다면 불꽃 레이드용으로 육성한다.

1. 화이트큐레무를 만들 예정이면 융합 파트너로 남길 레시라무를 먼저 분리한다.
2. 자체 육성용은 공격 IV가 높은 개체를 우선한다.
3. `불꽃엄니 + 크로스플레임`을 확인한다. 크로스플레임은 이벤트 제공 이력이 있지만 현재 대단한 기술머신스페셜로 반드시 얻을 수 있다고 단정하지 않으며, 게임 기술 목록에서 습득 가능 여부를 먼저 확인한다.
4. Lv.30에서 불꽃 약점 레이드의 사용 빈도를 확인하고, 주력이면 Lv.40까지 강화한다.
5. 레이드만 사용할 때 기술 해방은 후순위다. Lv.50은 장기 주력 한 마리에만 투자한다.
