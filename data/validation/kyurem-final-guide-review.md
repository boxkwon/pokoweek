## 1. 큐레무 최종 육성 가이드

### 최종 결론

융합 재료가 있다면 **큐레무 본체를 먼저 최대 강화하지 말고, 화이트용과 블랙용 개체를 먼저 정한다.** 두 폼을 모두 만들 계획이면 큐레무가 2마리 필요하다.

본체 육성은 다음 조건일 때만 진행한다.

- 화이트·블랙용 큐레무를 이미 따로 확보했다.
- 본체를 PvP 또는 특정 레이드에서 직접 사용할 계획이 있다.
- 융합과 필드 효과에 사용할 큐레무 사탕을 별도로 남겼다.

### 먼저 할 일

1. 가장 좋은 큐레무를 화이트용·블랙용으로 나눈다.
2. 각 큐레무가 `Glaciate`를 알고 있는지 따로 확인한다.
3. 레시라무·제크로무, 각 에너지 1,000, 필요한 사탕을 확보한다.
4. 융합에 쓰지 않는 큐레무만 본체 육성을 검토한다.

### 추천 기술

- 레이드 검토 조합: `Dragon Breath + Glaciate`
- PvP 검토 조합: `Dragon Breath + Glaciate + Dragon Claw`

`Glaciate`는 정규화 데이터에서 elite 기술로 확인된다. 대단한 기술머신 사용 가능 여부는 실제 게임 화면에서 확인한 뒤 사용한다. PvP 조합은 리그별 시뮬레이션을 완료한 최적 조합이 아니다.

### 강화·해방·XL 판단

- Lv.30: 본체를 바로 사용할 이유가 있을 때만 조건부.
- Lv.35·40: 융합 준비를 모두 마쳤고 본체 사용에서 전력 부족이 확인될 때.
- Lv.50: 기본 보류. 융합 두 폼을 준비한 뒤에도 본체 PvP 사용을 확정한 경우에만 재검토.
- 기술 해방: PvP에서 두 스페셜 기술을 실제로 사용할 때만 조건부.
- XL사탕: 본체보다 선택한 융합 폼에 우선한다.

## 2. 화이트큐레무 최종 육성 가이드

### 최종 결론

**범용적인 얼음 레이드 역할이 필요하면 화이트큐레무를 먼저 만든다.** `Ice Fang + Ice Burn`이 모두 얼음 타입이어서 사용 목적이 명확하다.

### 융합 전 확인

1. 화이트용 큐레무가 `Glaciate`를 알고 있는지 확인한다.
2. 레시라무 1마리, 블레이즈 에너지 1,000, 큐레무·레시라무 사탕 각 30개를 준비한다.
3. Ice Burn 필드 효과를 쓸 계획이면 별의모래 5,000과 큐레무 사탕 5개 단위의 사용분을 강화 자원과 분리한다.

### 추천 기술

- 레이드: `Ice Fang + Ice Burn`
- PvP 검토: `Ice Fang + Ice Burn`

Ice Burn은 PvE에서 위력 90, 에너지 50, 시전 시간 2,000ms다. PvP에서는 위력 120, 에너지 60이며 30% 확률로 상대 방어를 1단계 낮춘다.

### 융합 후 실행 순서

1. Ice Burn으로 정상 변환됐는지 확인한다.
2. 레이드용 노말 기술을 Ice Fang으로 맞춘다.
3. Lv.30까지 강화해 실제 얼음 파티에 넣는다.
4. 기존 얼음 팀보다 추가 전력이 필요하면 Lv.35로 올린다.
5. 여러 얼음 약점 레이드에서 반복 사용할 계획이면 Lv.40으로 올린다.
6. 장기 최우선 얼음 공격수로 확정하고 XL 296개를 감당할 때만 Lv.50을 선택한다.

### 기술 해방·XL 판단

- 레이드만 사용: 기술 해방은 후순위.
- PvP 사용: 리그와 두 번째 스페셜 기술을 정한 뒤 조건부 투자.
- XL사탕: Lv.40을 실제로 사용한 뒤에도 전력 개선이 필요할 때만 투자.

## 3. 블랙큐레무 최종 육성 가이드

### 최종 결론

**Dragon Tail과 Freeze Shock이 모두 유효한 명확한 상대가 있거나 Freeze Shock 필드 효과가 필요하면 블랙큐레무를 먼저 만든다.** 범용 얼음 역할만 필요하다면 화이트가 더 단순하다.

### 융합 전 확인

1. 블랙용 큐레무가 `Glaciate`를 알고 있는지 확인한다.
2. 제크로무 1마리, 볼트 에너지 1,000, 큐레무·제크로무 사탕 각 30개를 준비한다.
3. Freeze Shock 필드 효과용 별의모래·사탕을 강화 비용과 분리한다.

### 추천 기술

- 레이드 조건부 조합: `Dragon Tail + Freeze Shock`
- PvP 검토 조합: `Shadow Claw + Freeze Shock`

Freeze Shock은 PvE에서 위력 160, 에너지 100, 시전 시간 1,500ms다. PvP에서는 위력 120, 에너지 60이며 30% 확률로 상대 공격을 1단계 낮춘다.

Dragon Tail은 드래곤, Freeze Shock은 얼음 타입이다. 따라서 두 기술을 단순히 “최고 조합”으로 취급하지 않고 상대 타입을 먼저 확인한다.

### 융합 후 실행 순서

1. Freeze Shock으로 정상 변환됐는지 확인한다.
2. 공략 상대가 드래곤·얼음 기술에 각각 얼마나 약한지 확인한다.
3. 맞는 상대라면 Dragon Tail을 설정한다.
4. Lv.30까지 강화해 실제 파티에서 사용한다.
5. 같은 역할에서 전력이 부족하면 Lv.35, 반복 주력이면 Lv.40으로 올린다.
6. 장기 사용 대상과 XL 296개가 모두 준비됐을 때만 Lv.50으로 올린다.

### 기술 해방·XL 판단

- 레이드만 사용: 기술 해방은 후순위.
- PvP 사용: Freeze Shock과 함께 쓸 두 번째 기술 및 리그가 확정됐을 때만 조건부.
- XL사탕: 화이트보다 블랙을 우선할 구체적인 상대가 반복 등장할 때만 투자.

## 4. 화이트와 블랙 비교

| 질문 | 화이트큐레무 | 블랙큐레무 |
|---|---|---|
| 먼저 만들 상황 | 얼음 공격수 팀이 부족함 | 드래곤·얼음 기술이 모두 유효한 목표가 있음 |
| 레이드 역할 | 일관된 얼음 타입 공격 | 드래곤 노말 + 얼음 스페셜 혼합 |
| 추천 조합 | Ice Fang + Ice Burn | Dragon Tail + Freeze Shock |
| 필드 효과 | 타겟 링이 느려져 Excellent 포획 보조 | 야생 포켓몬 움직임을 멈춰 포획 보조 |
| 투자 난이도 | 역할이 단순해 단계 결정이 쉬움 | 상대 타입 확인이 먼저 필요함 |
| 기본 우선순위 | 범용 얼음 목적이면 우선 | 명확한 대상 또는 필드 효과 목적이면 우선 |

### 제한 비교 결과

동일한 Dragon/Flying 상대와 같은 계산 방식에서:

| 조합 | 상대 주기 지표 |
|---|---:|
| 화이트 — Ice Fang + Ice Burn | 18,460.357 |
| 블랙 — Dragon Tail + Freeze Shock | 17,979.145 |
| 가라르 불비달마 — Ice Fang + Avalanche | 13,965.751 |
| 드닐레이브 — Ice Fang + Avalanche | 13,487.835 |
| 맘모꾸리 — Powder Snow + Avalanche | 12,724.224 |
| 오리진 펄기아 — Dragon Tail + Draco Meteor | 11,048.960 |
| 레쿠쟈 — Dragon Tail + Outrage | 10,310.749 |

이 표는 실제 DPS/TDO 순위가 아니다. 기본 공격, 기술 위력·에너지·시전 시간, 자속, 타입 상성만 사용하며 생존과 보스 방어를 반영하지 않는다. Dragon/Flying이라는 특정 조건에서만 비교한다.

결론은 다음과 같다.

- 일반적인 얼음 공격 역할은 화이트가 더 이해하기 쉽고 일관된다.
- 블랙은 특정 상대에서 강한 조건부 역할이 있지만 기술 타입이 섞여 있다.
- 전체 공격수 순위나 모든 보스에 대한 우위를 의미하지 않는다.

## 5. 둘 다 만드는 경우 투자 순서

1. Glaciate 보유 큐레무 2마리를 화이트용·블랙용으로 지정한다.
2. 각 파트너와 융합 에너지 1,000씩, 큐레무 사탕 총 60개, 파트너 사탕 각 30개를 확보한다.
3. 범용 얼음 팀이 부족하면 화이트를 먼저 융합한다.
4. 특정 혼합 약점 상대나 Freeze Shock 필드 효과 목적이 있으면 블랙을 먼저 융합한다.
5. 첫 번째 폼만 Lv.30까지 강화해 실제 사용한다.
6. 첫 폼이 팀 문제를 해결하면 두 번째 폼은 Lv.30 또는 미강화로 대기한다.
7. 두 폼 모두 반복 사용할 이유가 확인되면 각각 Lv.35→40으로 올린다.
8. XL사탕 296개 투자는 둘 중 장기 주력 한 폼에 먼저 집중한다.

## 6. 특별 기술이 없는 경우

### A. Glaciate를 보유한 큐레무

- 융합 가능하다.
- 화이트 융합 시 Ice Burn, 블랙 융합 시 Freeze Shock으로 변환된다.
- 분리하면 전용 기술이 Glaciate로 되돌아간다.
- 전투용 융합에 우선 사용할 개체다.

### B. Glaciate가 없는 큐레무

- 융합 자체는 가능하다.
- 하지만 Ice Burn 또는 Freeze Shock 변환 조건을 충족하지 않는다.
- Ice Burn과 Freeze Shock은 일반·대단한 기술머신스페셜로 직접 배울 수 없다.
- 전투용이라면 다른 Glaciate 개체를 선택하거나 Glaciate 습득 기회를 기다리는 것을 권장한다.
- PoGo API는 Glaciate를 elite 기술로 분류하지만, 실제 대단한 기술머신 목록과 이벤트 조건은 융합 직전에 게임 화면에서 재확인한다.

전용 기술이 없는 상태로 융합 에너지 1,000을 사용하는 것은, 전용 기술이 필요 없다는 목적이 분명할 때만 선택한다.

## 9. 검증된 사실과 분석 의견

### 검증된 사실

- 큐레무·융합 폼의 타입, 기본 능력치, 현재·elite·융합 전용 기술 수치.
- 융합 재료와 파트너.
- Glaciate의 Ice Burn/Freeze Shock 변환 조건.
- 전용 기술의 기술머신 습득 제한과 분리 시 복귀.
- 융합 상태의 교환·박사 전송·Pokémon HOME 전송 제한.
- 필드 효과 비용과 동시 사용 제한.
- 레벨별 CPM, 강화 비용, 15/15/15 CP 계산.

### 분석 의견

- 화이트를 범용 얼음 역할의 기본 우선순위로 두는 판단.
- 블랙을 특정 상대·필드 효과 목적의 우선순위로 두는 판단.
- Lv.30→35→40→50 단계별 중단 조건.
- 기술 해방과 XL사탕의 투자 순서.

분석 의견은 Evidence를 바탕으로 한 전략적 권고이며 게임 규칙 자체가 아니다.

## 10. 게시 전 남은 위험 및 검토 항목

- 실제 보스 방어·생존·회피를 반영한 레이드 시뮬레이션은 수행하지 않았다.
- 대표 비교는 맘모꾸리·가라르 불비달마·드닐레이브·레쿠쟈·오리진 펄기아로 제한했다.
- PvP 리그별 실드·개체값·매치업 시뮬레이션은 수행하지 않았다.
- `pokemon_max_cp` 엔드포인트의 큐레무 4,090은 레벨 50 공식 계산값 4,041과 맞지 않아 레벨 50 근거로 사용하지 않았다.
- Glaciate의 실제 대단한 기술머신 제공 상태는 투자 직전 게임에서 재확인해야 한다.
- 게임 밸런스와 기술 수치는 향후 변경될 수 있으므로 API 스냅샷 변경 시 재검토한다.

위 위험은 가이드의 조건부 판단과 제한을 명시한 상태에서는 게시를 무기한 차단할 사유가 아니지만, 실제 승인 전 사람 검토는 필요하다.
