# Raid artwork sources

The `pokeapi-*.png` files in this directory were retrieved on 2026-11-25 from the
[PokeAPI sprites repository](https://github.com/PokeAPI/sprites), using its
`sprites/pokemon/other/official-artwork/` collection.

- Repository license: CC0 1.0 Universal
- Image copyright notice: image contents are Copyright The Pokémon Company
- Source repository license file: https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt

Form-specific artwork is used where the repository supplies it. Shadow,
costume, and Super Mega forms without a matching asset deliberately use the
same species' base-form artwork while the visible Korean form name and raid
category remain unchanged.
